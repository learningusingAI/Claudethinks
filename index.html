    Sinkron ke GitHub

    Catatan disimpan sebagai file JSON di repo private milikmu. Gunakan fine-grained token yang hanya punya akses ke repo itu, dengan permission Contents: Read and write.

    Tanpa centang, token hilang saat tab ditutup. Dengan centang, token tersimpan tanpa enkripsi di browser ini — jangan centang di perangkat bersama.

    Catatan tersimpan di browser ini (localStorage, tidak terenkripsi) dan, jika diatur, di repo GitHub private milikmu. Riwayat git menyimpan semua versi, termasuk catatan yang sudah dihapus — jangan simpan data sensitif.
